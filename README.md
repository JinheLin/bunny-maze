# 兔兔迷宫 · 森林小探险

专为一年级孩子设计的单页迷宫游戏，适配安卓平板、电脑与手机。无外部依赖，无广告或倒计时。

**在线游玩：[https://jinhelin.github.io/bunny-maze/](https://jinhelin.github.io/bunny-maze/)**

直接在迷宫上滑动，或点按小兔相邻的格子。界面没有方向按钮和大块操作说明图。

## 开始玩

用浏览器打开 `dist/index.html` 即可游玩。联网部署后也可添加到安卓主屏幕。支持离线缓存的浏览器在成功加载一次后，可以断网继续玩；缓存和主屏幕安装能力取决于浏览器、存储权限与部署环境。

本地预览：在本文件所在目录运行 `python3 -m http.server 8000 --directory dist`，打开 `http://localhost:8000`。

## 操作

- 在迷宫上向上、下、左、右滑动，也可点按小兔相邻的格子。
- 连续滑动可走多步；电脑支持方向键和 WASD。
- 轻松 / 进阶 / 挑战分别使用 6×6 / 8×8 / 11×11 迷宫，每张都有通路。
- 「给我一点提示」会显示前两步正确路线，5 秒后消失。
- 「换一张迷宫」生成新地图；「重走」回到当前地图起点。
- 点击右上角开启音效或进入全屏。没有自动播放音效。
- 刷新会恢复进度，成功次数保存在当前浏览器。清除浏览器数据会重置记录。

## 平板体验

横屏时迷宫与控制区并排；竖屏时控制区移到迷宫下方。游戏区域支持单指滑动和指针捕获，避免拖动时页面滚动。页面支持安全区域和减少动态效果偏好。

原型已做浏览器响应式与交互验证；OPPO Pad3 的真机全屏、安装和触控行为仍应以实际浏览器测试为准。

## 文件

`dist/` 内所有文件都是部署产物，可直接放在静态网页服务器上；不需要安装依赖或构建。`maze.js` 是迷宫生成与寻路逻辑，`app.js` 是游戏交互，`styles.css` 是响应式布局。

## GitHub Pages 部署

仓库使用 GitHub Actions 将 `dist/` 自动发布到 GitHub Pages。修改后推送到 `main`，或在 Actions 中手动运行「Deploy GitHub Pages」即可更新网页。

部署配置位于 `.github/workflows/pages.yml`；仓库 Settings → Pages 的发布方式设为 GitHub Actions。

所有页面资源均使用相对路径，支持 `/bunny-maze/` 这样的项目子路径。游戏进度只保存在当前设备的浏览器中。
